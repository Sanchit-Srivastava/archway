# Tier 3 (desktop) — GUI apps layered on the KDE Plasma archinstall baseline
#
# CONTEXT: archway assumes the system was installed via archinstall using the
# **KDE Plasma** desktop profile. That profile ships:
#   - plasma-meta  (pulls the full `plasma` group: bluedevil, plasma-desktop,
#                   plasma-nm, plasma-pa, plasma-workspace, kscreen, sddm-kcm,
#                   kwallet*, polkit-kde-agent, xdg-desktop-portal-kde, …)
#   - konsole, dolphin, sddm
#   - pipewire stack (already in T2)
# These provide the "robust baseline GUI" — if T4 (DMS / niri) breaks, the
# user logs into Plasma from SDDM and has a fully functional daily driver.
#
# This file therefore lists only what archway *adds* on top of plasma-meta:
# additional GUI apps, alternative file managers, the LaTeX/PDF stack, the
# polkit-gnome agent (used by non-KDE sessions like niri), and so on.
#
# Anything provided by `plasma-meta` is intentionally OMITTED — pacman -S
# --needed in bootstrap.sh would be a no-op for those, but listing them here
# would blur the line between "archinstall baseline" and "archway additions"
# and confuse the package audit.
#
# Keep packages grouped by section; keep entries alphabetized within a section.
