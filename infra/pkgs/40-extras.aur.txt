# Tier 4 (extras) — AUR packages
#
# AUR is intentionally placed in T4 (the fragile tier). AUR builds can fail
# from upstream URL drift, missing keyring updates, or transient build deps.
# Putting them in T4 means a failure here NEVER blocks T1/T2/T3 from
# completing — the system remains fully usable on Plasma + CLI tools.
#
# AUR packages stay out of the baseline so failures here cannot break T1-T3.
